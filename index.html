Brand assets

Logos, ascenders, the promise, icons and fonts with stable public URLs, for email signatures, websites and Claude Design pages. Each file is available as SVG and as a transparent PNG (icons as SVG only). Use the PNG in email signatures. Source: SQLI Brand Guidelines v1.1.

Repository: github.com/SQLI-Spain-Internal/sqli-brand-assets

Colours

Cream
#FFFAF0
Midnight Blue
#0F0E2B
Sky Blue
#6DA5FF
Cobalt Blue
#1F24E9

Logo colour per background. On Cream, Midnight Blue or Cobalt Blue. On Midnight Blue, Cream or Sky Blue. On Sky Blue, Midnight Blue. On Cobalt Blue, Cream.

Logo

The safe-zone versions include the clear space around the logo.

Ascenders

Promise

File names give the type colour first, then the ascender colour. Inline is one line, wrapped is two lines.

Icons

Cobalt Blue icons for Cream backgrounds, Sky Blue icons for Midnight Blue backgrounds. URL pattern: https://sqli-spain-internal.github.io/sqli-brand-assets/icons/cobalt/<name>.svg and https://sqli-spain-internal.github.io/sqli-brand-assets/icons/sky/<name>.svg.
